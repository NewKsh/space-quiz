# 우주 한 바퀴

한국어 우주 탐사 퀴즈입니다. 달 탐사부터 누리호와 다누리까지, 4지선다 10문항을 풀며 우주 상식을 알아보세요.

**웹사이트:** [우주 한 바퀴 시작하기](https://newksh.github.io/space-quiz/)

## 기능

- 문항 진행 막대와 실시간 점수, 정답·오답 애니메이션 및 짧은 해설
- 이모지 결과 화면과 문항별 복습, ‘오답만 보기’ 필터
- 현재 연속 정답, 최고 점수 및 최장 연속 정답 기록
- 선택적으로 켤 수 있는 숫자·문자 단축키와 기본 키보드 조작
- 모바일 레이아웃, 시스템 라이트·다크 테마 및 동작 줄이기 설정 지원

## 로컬 실행

저장소를 내려받거나 복제한 다음 `index.html`을 브라우저에서 열면 됩니다.

```sh
git clone https://github.com/NewKsh/space-quiz.git
```

복제된 `space-quiz` 폴더에서 `index.html`을 더블클릭하세요. 서버, 패키지 설치, 빌드가 필요하지 않으며 인터넷 연결 없이도 실행됩니다. HTML, CSS, JavaScript는 모두 이 파일에 포함되어 있습니다.

Tab으로 버튼에 이동하고 Enter 또는 Space로 누를 수 있습니다. ‘빠른 답 선택 켜기’를 선택하면 퀴즈 영역 안에서 `1`~`4` 또는 `A`~`D`로 답을 선택할 수도 있습니다. 이 설정은 기본적으로 꺼져 있습니다.

최고 점수와 최장 연속 정답은 브라우저의 `localStorage`에 저장됩니다. 브라우저가 저장을 차단하면 안내를 표시하고, 기록은 이번 방문에서만 유지됩니다. 브라우저·기기·사이트 주소가 달라지면 기록이 공유되지 않으며, 로컬 파일 실행 시 저장 동작은 브라우저와 파일 경로에 따라 달라질 수 있습니다.

## GitHub Pages 배포

`.github/workflows/pages.yml`이 배포를 담당합니다.

1. `main`을 대상으로 하는 PR에서 HTML 진입점과 인라인 JavaScript 구문을 검사합니다.
2. `main`에 변경 사항이 푸시되면 같은 검사를 수행하고 `index.html`만 Pages 아티팩트에 담습니다.
3. `github-pages` 환경에 배포합니다. 워크플로 화면의 **Run workflow**로 `main` 배포를 다시 실행할 수도 있습니다.

저장소의 **Settings → Pages → Build and deployment → Source**는 **GitHub Actions**로 설정되어 있어야 합니다. README와 Git 메타데이터는 사이트 배포물에 포함되지 않습니다.
